# 技术细节 · 星际发射指挥官 StarPinyin Commander

> 面向开发者/维护者。面向孩子和家长的上手说明见仓库根目录 [README.md](../README.md)。
> 设计规格与里程碑演进见 [star-pinyin.md](../star-pinyin.md)。

## 技术栈
- 后端：原生 Node.js `http`，**零依赖**，数据持久化为本地 JSON（`data/*.json`，支持家长直接编辑/热注入）。
- 前端：原生 HTML5 + CSS3 + Vanilla ES Modules，无构建工具。
- 图形/动效：分层 SVG + Canvas（后续里程碑）。
- 音频：Web Audio 程序化合成 + 本地人声降级 `speechSynthesis`（后续里程碑）。

## 启动服务
```bash
node server.js            # 默认 http://0.0.0.0:3000
# 或
npm start
# 自定义端口
PORT=8080 node server.js
```
启动后控制台会打印本机与局域网地址。**iPad Safari 打开局域网地址**（如 `http://192.168.x.x:3000`），
用「分享 → 添加到主屏幕」即可以 PWA 全屏竖屏运行。

> 若本机 `node` 不在 PATH，可使用运行时自带的 Node，例如：
> `& 'C:\Users\panft\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe' server.js`

## 验证词库的规则准确性（2224 条）
```bash
npm test                  # 引擎单元测试 + 种子验收 + 词库结构验收
npm run validate          # 种子配额 + 全库逐条规则验收
npm run wordbank:check    # 三批扩展词库体检（只报不写盘）
```
也可在浏览器控制台验证：打开主页 → 「进入指挥中心」→ 「运行拼音规则自检（全库）」，
或直接执行 `await runPinyinSelfTest()`，明细以 `console.table` 输出。

验收标准：
- 40 个种子任务「拆分 / 标调 / j·q·x 去点」100% 准确，种子配额 10 两拼 / 15 三拼 / 8 j-q-x+ü / 7 整体认读。
- 全库 2224 条（40 种子 + 960 扩展 + 1224 课文同步扩展）逐条通过规则校验，且汉字唯一、id 唯一、干扰项不含正确答案。

## 词库：40 个种子 + 960 个扩展 + 课文同步扩展（m_1001+）
- 扩展词条分三批：**三年级专项**（m_041–m_140，部编版三年级上下册「会写字」+ 三年级测试高频词）、
  **小学扩展**（m_141–m_500）、**进阶扩展**（m_501–m_1000，补水三~六年级会写字与低年级高频字）。
  覆盖两拼（平翘舌、前后鼻音、n·l+ü）、三拼、j-q-x+ü 摘墨镜、整体认读、零声母五种考法。
- 生成方式：`npm run wordbank`，依次运行 `scripts/expand-missions-grade3.mjs`、
  `scripts/expand-missions-primary.mjs`、`scripts/expand-missions-1000.mjs`，
  共用 `scripts/wordbank-lib.mjs`。拼音由 `parseSyllable` 自动拆出声母 / 介母 / 韵母 / 声调，
  再由 `validateMission` 终审；干扰项按「平翘舌 / 前后鼻音 / j·q·x 不能与合口呼相拼」规则生成，
  每槽 1–3 个且绝不含正确答案。
- 选字约定：三批扩展（m_041–m_1000）只收**单音字**，避开 长 / 行 / 重 / 教 / 觉 / 卷 / 藏 等多音字；
  **课文同步扩展（m_1001+）与教材引用条目按写字表全覆盖**，多音字按该课语境读音入库，
  TTS 兜底带词组上下文（「长大的长」）保证读对，音节读音走离线 wav 不受影响；
  词组不选该字读轻声的词（如「石头」），只有轻声读法的字（们/么）标 skip 不入词库。
- 幂等：重复运行只重建各自的 id 区间，不会动家长在后台注入的 `m_p_*` 紧急载荷。
- 2224 条构型分布：两拼 1487 · 三拼 384 · 整体认读 223 · j/q/x+ü 86 · 零声母 44；
  全库是此消彼长的加权抽题池；**任务难度已取消**，抽题只按课文进度圈定字池 + 错题率加权（不再按难度档混入三拼 / 易混音）。
- 音节读音已全部离线化到 `public/audio/voice/*.wav`（957 个音节，统一响度）：来自真人录音库
  [audio-cmn](https://github.com/hugolpz/audio-cmn)（王晨 录音 · CC-BY-SA 3.0，`npm run voice:import`），
  库缺失的个别音节保留 TTS 预生成兜底；缺失时才退回旧 mp3 或现场合成。

## 课文同步：词库跟着 2026 最新统编（人教）版语文课本走

词库与 **2024 年修订版统编语文教材**（2024 秋一年级启用、2025 秋二三年级启用、2026 秋全面覆盖，
即 2026 年在用的最新版）一~三年级**课文同步**：

- **覆盖**：一~三年级上下册的**识字表（会认）∪ 写字表（会写）**，按「年级 → 学期 → 课文（学习顺序）」组织。
  六册官方字数全部吻合课本页脚：

  | 册 | 会认 | 会写 | 目录生字 |
  |---|---|---|---|
  | 一年级上册 | 280 | 100 | 280 |
  | 一年级下册 | 410 | 200 | 410 |
  | 二年级上册 | 460 | 250 | 460 |
  | 二年级下册 | 450 | 250 | 450 |
  | 三年级上册 | 250 | 250 | 250 |
  | 三年级下册 | 250 | 250 | 250 |

  去重后 **2098 字**（新版教材存在少量同册/跨册重复，如实保留，任务归首次教学位置；纯轻声 3 字标 skip），
  **2095 字全部入库可出题**。
- **为什么字源是「会认」而不只是「会写」**：本游戏练的是拼音读音与拼读，拼音本来就跟着识字走。
  只认不写的课——识字1《天地人》、各略读课文、一年级的汉语拼音单元——因此同样能出题。
  另外识字表还给出了课本真实学习顺序，所以一年级的汉语拼音第 3–14 课也被正确插进目录
  （只靠写字表的话这些单元会整个缺失）。
- **认/写分离的处理**：新版教材写字表与识字表不是同一套字。实测一年级上册 100 个会写字全在 280 会认字内，
  但其中 34 字的「认读课」与「会写课」不是同一课（如「天」在《天地人》认读、在《四季》才要求会写）。
  目录按**首次教学位置**只收一次，并用 `writing` / `writeSeq` 标注它同时是会写字及其会写课序号。
  新版教材把部分会写字移到了「语文园地 · 我会写」，这些字也按学习顺序收录（kind=语文园地）。
  本课读轻声但有常用本音的字（了/子/的/着/得/夫…）按**本音**入库（词组用本音词，note 注明课文轻声）；
  纯轻声字（们/么/啊）无法出拼音题，目录中标 `skip` 保留、不入词库。
- **目录数据**：`data/textbook.json`（汇编产物）← `data/textbook-src/grade{1,2,3}.json`（调研源，含来源 URL）。
  每个任务带 `textbook: {grade, term, seq, no, kind, unit, title}` 引用，简报界面显示「📖 一年级上册 · 识字2《金木水火土》」。
- **学习进度可选**：机库「① 课文同步」面板——年级（自由巡航 / 一~三年级）→ 学期（上册 / 下册）→
  课文进度（横滑课文芯片，可选到具体一课；**「全册」芯片垫在最后一格**，虚线边框表示整册复习）。
  选择持久化到服务端档案（`progress.textbook`），
  抽题只从**累计学过**的字里出（一年级上册第 1 课到所选课文），紧急载荷不受进度限制。
  「自由巡航」= 全部词库（旧体验）。进度内某模式（三拼/易混音）无题时自动退回进度内综合巡航。
- **单元完成规则**：这里的「单元」= **一课**（识字1 / 识字2 / 第1课 / 语文园地 / 汉语拼音…，以 `seq` 标识），
  即机库现有的**课文芯片**（不另设单元行）。点一个课文芯片 = 生成一份**固定题单**逐题发射：
  **本课所有新出现的字**（按教材顺序，全部收入）+ **过往复习字**（本课之前累计学过的字，**错题优先**、其余随机）。
  **复习名额 = 单元总字数 − 本课新字数**；总字数由家长后台「学习管理」**可选 10~20（默认 15）**（`progress.unitTotal`，`POST /api/unittotal`），
  过往字不足名额则全取；本课新字已≥总字数时只练新字、不另抽复习。改总字数只影响之后新建的题单（未完成的当前题单恢复时不变）。
  **同一个汉字在本单元只出现一次**（新字唯一、复习字与新字不重叠），**答错也不在本题单内重复**。
  「下一题」沿题单前进，题单做完即「本单元完成」，结算页默认（主按钮）为「返回指挥中心」、「再练一遍 ↻」为次选项；再点同一课（未完成）恢复进度，已完成则重抽复习。
  **完成即默认下一课**：结算点「返回指挥中心」（或做完单元后重进指挥中心，`profile.unitSession.done`）→ `selectNextUnit` 按 `flattenLessons` 教材顺序选中下一课并建单（自动跨册 / 跨年级；目录最后一课保持当前课；进度已被家长改到别课时尊重其选择，不前进）。验收：`node scripts/debug-unit-next-default.mjs`。
  **已完成单元置灰**：`GET /api/profile` 返回 `completedLessons`（已完成课时键 `grade-term-seq` 数组，与课时奖励同口径 = 该课全部可出题生字 `attempts>0`），
  机库课文芯片据此加 `.tb-lesson.done`（灰字 `--text-mute` + 凹陷底 `--space-1`，三套皮肤自适应，title 追加「（已完成）」）；
  选中复习时选中态完全接管置灰（`:not(.active)`），「全册」芯片不置灰。验收：`node scripts/debug-lesson-done-gray.mjs`。
  **错题生命周期（修正分散在后续不同单元，不是在当前单元练三次）**：一次作答有错 → 入错题池（`stat.wrong`）并清零连续计数；
  错题在**后续单元复习**里「错题优先」被再次抽到，每全对一次算修正 1 次（`stat.fixes`），
  **连续修正满 3 次毕业**（`wrong=false`，不再错题优先，但仍可作普通过往字随机抽到）；中途再错则计数清零。
  选全册 / 自由巡航即作废题单退出单元模式；紧急任务绕过题单。
  **底部完成进度条**：单元练习时游戏画面底部常驻（`#unitProgress`，`State.missionUnit` 驱动，跨简报/组装/声调/结算），
  **仅数字 `cursor/total` + 细条，无文字标签**；透明底、`pointer-events:none` 不拦截触摸、低透明度，低调不干扰做题；
  `body.unit-progress-on #game` 预留少量底部空间。
  **发射动画**：单元题单里仅**第一题**与**做完整份题单的最后一题**播放完整火箭发射动画，中间各题跳过直接结算
  （`unitFxPlays`：`cursor===0 || cursor===total-1`；单题题单首尾重合播一次）；非单元题单仍按家长 `launchFx` 选项。
  纯逻辑见 `public/js/unit-session.js`（`buildUnitQueue` / `updateWrongStat` / `unitFxPlays`），题单持久化在 `progress.unitSession`（含 `seq` / `label`）。
- **多音字**：教材生字含多音字（长/行/重/只…），按该课语境读音入库；TTS 兜底一律带词组上下文
  （「长大的长」），音节读音仍走离线预生成 wav，保证读对。
- **跨年级重复字**：新版写字表存在少量跨年级重复（如果/年/玩 同时列入一、二年级写字表，统编旧版亦有 16 个重复字）。
  目录保留各册完整写字表；任务归属与抽题字池以**首次教学位置**为准（重复字在后续年级进度中自然已会）。
- **同步命令**：`npm run textbook`（`scripts/sync-textbook-wordbank.mjs`）——校验调研源 → 汇编目录 →
  给旧条目打教材引用 → 按教材读音重建冲突条目（种子除外）→ 补齐缺失生字（**m_1001+** 教材扩展块）。
  幂等，不动家长注入 `m_p_*`；`npm run wordbank` 末尾自动接同步。`npm run textbook:check` 只体检。
- **API**：`GET /api/textbook`（目录 + 当前进度 + 字池规模）、`POST /api/textbook/select`
  `{grade, term, seq}`（`grade=null` 改回自由巡航；非法 422；选择即作废单元题单）、
  `POST /api/unit/select` `{grade, term, seq}`（选一课生成/恢复单元题单，返回 `session` 进度视图；非法 422）。
- **验收**：`node test/textbook.test.mjs`（目录结构 / 生字全覆盖 / 引用一致 / 进度纯逻辑）、
  `node test/textbook-api.test.mjs`（隔离数据副本上起真实服务，验证过滤 / 校验 / 紧急豁免）、
  `node test/unit-session.test.mjs`（课题单构建 / 错题池 / 首尾动画判定纯逻辑）、
  `node test/unit-api.test.mjs`（单元题单 / 错题重复 / 3 次毕业 / 复习错题优先 / 退出与清空）、
  `node scripts/debug-textbook-ui.mjs`（面板 + 简报截图）、`node scripts/debug-unit-ui.mjs`（课文芯片选题单 + 状态截图）。

  四周留呼吸边距，不顶屏幕边缘、不留大块空白；火箭舞台自动占满剩余空间。
- **组装台「复读」+ 错两次自动帮扶**：托盘标题行右侧常驻「复读」按钮（竖屏 / 横屏 / 矮横屏均可见，矮屏自动收紧）：
  无线电滋滋声 + 真人语音重读目标词「XX的X」（**不带简报的「载荷确认」前缀**），组装中随时可再听。

  帮扶目标选择为纯逻辑 `nextHintSlot`（浏览器/Node 共用）。

## 全局真人语音（Qwen-Audio-TTS）

所有语音（系统提示、任务简报、倒计时、慢速拆读、错误反馈、入轨读音）均使用 **qwen-audio-3.0-tts-plus** 真人音色。
该模型实测可用音色：`longanhuan_v3.6`（默认）、`longanlingxin`（温暖女声）、`longanlufeng`（明朗男声）、`longanlingxi`
（其余 v3.6 音色在这条接口上会报 `InvalidParameter … Engine error [411]`）。

**家长的 TTS合成API设置（`/admin.html#voice`）**：只填 API 地址 + Key，点「自动获取模型 / 音色」（或 Key 失焦、
首次打开「发音」页）即可——**系统音色没有查询接口**，所以模型走真实 `/v1/models`，音色用内置表
`public/js/tts-catalog.js` 按模型解析（音色必须与模型同族，跨模型混用接口直接报错），再合并接口能列出的
自建/复刻音色；下拉框都有「手动填写…」入口。`测试合成` 会先保存再合成，改完音色立即试听不用再点保存。

**发音链路（按优先级）**
1. 音节读音：`public/audio/voice/{拼音}{声调}.wav` —— **真人库 / AI 双源并存，可切换**：
   - `lib/{拼音}{声调}.wav` = 真人录音库 [audio-cmn](https://github.com/hugolpz/audio-cmn)（王晨 录音 · CC-BY-SA 3.0，
     署名见 `public/audio/voice/CREDITS.md`），`npm run voice:import` 导入，**「重新生成」永不覆盖**；
   - 根目录 `{拼音}{声调}.wav` = AI TTS 合成（`npm run voice:syllable` / 后台「重新生成」只写这里）；
   - 播哪份由 `data/voice-source.json` 决定（全局默认 + 逐音节覆盖），服务端按配置解析同一 URL，客户端零改动；
   - 家长后台「读音来源」按钮切全局默认；[音节自检页](public/voice-check.html)逐音节切换 + `?src=lib|tts` A/B 对比试听；
   - 首选源缺失自动退回另一份，绝不留缺。
2. 旧版音节录音：同名 `.mp3`（40 个种子音节的历史文件，作兼容兜底）。
3. 呼读音（声母/介母/韵母）：`public/audio/voice/part/{字母}.mp3`（`npm run voice:part`，配方经 ASR 校验）。
4. 其它任意文本：服务端 `/api/tts` 合成并缓存到 `data/voice-cache/`（`npm run voice:system` 预热）。
5. 浏览器 `speechSynthesis` 仅作最后兜底（机器人腔，正常情况不该被触发）。

**为什么单字读音要「先取再播」**
服务端首次合成要 1~3 秒。旧实现让 `<audio>` 边下边播，`play()` 很容易被浏览器拒绝，于是**立刻降级到机器语音**——
听起来忽高忽低、明显「很奇怪」。现在 `speakText` 先 `fetch` 成 blob 再播（20s 超时），只有服务端真的失败才降级。

**重新生成后立刻听到新读音（缓存语义）**
「重新生成」是原地覆盖同名 `wav`（URL 不变），而浏览器媒体缓存会按 URL 缓存旧音频、无视 `no-cache`、
且跨页面刷新仍在——曾导致「重新生成后试听还是旧发音，刷新也没用」。现在：
- 家长端试听 / 音节自检页 / 孩子端读音一律 `fetch(cache:'no-store')` 取字节成 blob 再播，每次都是磁盘上最新那份；
- 静态音频带 `ETag` / `Last-Modified`（未变回 304，覆盖后 ETag 变化立即取新），且 `/audio/voice/*` 一律读 `VOICE_OUT_DIR`；
- `/api/tts` 改为 `no-cache`（服务端磁盘缓存已避免重复合成），换音色/设置后不再播 24h 旧缓存。
回归测试：`test/voice-admin-api.test.mjs` [8]、`test/part-voice.test.mjs`、`scripts/debug-voice-admin.mjs`。

**发音自检 / 个别音节微调**
- 打开 `http://<host>:<port>/voice-check.html`：按拼音列出全部音节，逐个试听、标记听感不对的。
  标记会自动 POST 到 `/api/voice/flags`（落盘 `data/voice-flags.json`），换浏览器/换设备也不会丢。
- 对标记的音节，可对个别音节换源（同一音节换字 / 从词组里切 / 指定毫秒区间）：
  ```json
  {
    "ju4":  { "text": "聚集", "from": 40, "to": 500 },
    "sen1": { "text": "森林", "from": 55, "to": 305 },
    "xie1": { "text": "一些", "pos": 1 },
    "sen1_alt": { "hanzi": "森" }
  }
  ```
  `hanzi` = 换个汉字读（孤立单字）；`text`+`pos` = 从该词里切出第 pos 个音节；`text`+`from`+`to` = 直接按毫秒切。
- `npm run voice:syllable -- --only ju4,sen1 --force` 只重做这几个（TTS 兜底源）；`--carrier` 可让全部音节都尝试「从词组里切」。
- 真人库导入：`npm run voice:import`（跳过已有 wav）/ `-- --force`（全部换成库录音）/ `-- --only ju4,sen1 --force`，产物落 `lib/` 独立目录。
  构建期需 ffmpeg（放 `tools/ffmpeg/ffmpeg.exe` 或 PATH）；mp3 缓存在 `data/voice-lib/`，
  覆盖率报告落盘 `data/voice-import-report.json`；库缺失（404）的音节自动保留现有 TTS 读音。
- **AI 重新生成不覆盖真人**：后台「重新生成」与 `npm run voice:syllable` 只写根目录 AI wav；
  两者切换见「发音链路」。回归测试：`test/voice-source.test.mjs`（双源解析/切换/重新生成隔离/ETag）。

**其它**
- API Key 运行时从环境变量 `QWEN_TOKEN_PLAN_CN_API_KEY` 或 DSH 凭据文件读取，**不写入仓库**。
- 换音色：`node scripts/gen-syllable-voice.mjs --force --voice <音色>`、`gen-part-voice.mjs --force --voice <音色>`、
  `gen-system-voice.mjs --force --voice <音色>`，或服务端环境变量 `TTS_VOICE`（同时改，否则音色不一致）。
- **预热整句语音**：`npm run voice:system` 把系统提示 / 倒计时 / 火箭名 / 全部简报短语（约 2300 条）合成到
  `data/voice-cache/`，孩子端 `/api/tts` 直接命中、断网也能播。
  - 缓存文件名是 `sha1("{音色}|{文本}")`，**音色必须与服务端一致**：脚本按同一口径解析
    （`--voice` > `data/tts-config.json.voice` > `TTS_VOICE` > 默认 `longanhuan_v3.6`）。
    在家长后台换过音色后，旧缓存按旧音色哈希，**必须重新预热一次**，否则每条都 miss（现场重新合成，慢且要联网）。
  - 全量串行约 1.5 小时；加并发可压到 10 分钟：`node scripts/gen-system-voice.mjs --concurrency 5`。
    中途断了直接重跑即可，已存在的文件会跳过（幂等）。

  火箭图鉴（16 枚，已解锁/未解锁）。
  火箭模型图为 **wan2.7-image 生成后抠透明**（`public/images/rockets/{id}.png`，`npm run rockets:images` 生成，加载失败回退 AI 火箭图标）。
- **系统自检**：位于家长后台 `/admin.html`「系统」页「系统自检」面板，对全部任务执行拆分/标调/j·q·x 去点校验（控制台 `runPinyinSelfTest()`）。
- **家长后台** `/admin.html`（手机/电脑均可）：分四页 —— **学习管理**（介母装配 / 紧急载荷注入 / 薄弱拼音标签）、
  **界面**（界面风格 / 图标风格 / 发射动画）、**发音**（读音来源 / TTS合成API设置 / 发音自检·重新生成 / 词库表格，四个独立面板）、**系统**（系统自检 / 一键清除学习记录）。
  页签吸顶（玻璃卡片，与面板同风格），`#study` / `#ui` / `#voice` / `#reset` 直达，本机记住上次停留页；
  **默认打开「界面」页**（只改外观，孩子误开无风险），其余三页需**繁体数字家长校验**——输入简体数字的繁体写法
  （一→壹 … 十→拾，答错换新题）才解锁，仅本次浏览器会话有效（关闭标签页重新上锁），防孩子错触。
  所有面板常驻 DOM，切页不打断发音播放与生成任务。验收：`node scripts/debug-admin-tabs.mjs`。
  - 近期薄弱拼音标签错误率排行（如「前后鼻音 35%」）。
  - **发射动画选项**：「每次完整播放」（默认）/「每单元仅首次」——后者每个课文单元的第一次发射播放完整动画，
    同单元后续发射跳过动画直接结算（练习更紧凑）。点选即存 `data/progress.json.launchFx`，孩子端每次点火前拉档案，
    下一局即生效无需刷新；「已发射单元」由作答统计推导（单元内任一词条练过即算，`/api/profile.launchedUnits`），
    清空学习记录后自然归零。没有单元归属的词条（汉语拼音课 unit=null、无教材引用扩展、紧急载荷）始终播放。
    验收：`node test/launchfx-api.test.mjs` + `node scripts/debug-launchfx.mjs`（后台点选 + 真实拖拽发射全流程截图）。
  - **介母装配选项**（「学习管理」页）：「孩子装配」（默认）/「自动预装」——三拼音节（声母+介母+韵母，如 ch-u-an → chuán）
    的介母舱段是否由孩子亲手装配。选「自动预装」后介母直接预装正确值（j/q/x 后 ü 显示去点书写形 u，不弹摘墨镜），
    托盘不再出介母零件，孩子只拼声母+韵母，降低三拼难度；两拼/零声母/整体认读不受影响。
    点选即存 `data/progress.json.medialMode`，孩子端每局组装前拉档案，下一局即生效无需刷新；清空学习记录保留该选项。
    验收：`node test/medialmode-api.test.mjs` + `node test/assembly.test.mjs`（布局纯逻辑）+ `node scripts/debug-medial-mode.mjs`（后台点选 + 真实拖拽组装截图）。
  - 紧急载荷注入：输入汉字 + 拼音（`chuán` 或 `chuan2`，`v`=ü），`parseSyllable` 自动辅助拆分声母/介母/韵母/声调/构型，家长微调后一键提交。
  - 词库管理（「发音」页）：查看全量词条与错题率，删除 / 取消紧急标记。表格单列**读音来源**（真人 / AI / 旧 mp3 / 缺失，
    悬停看双源库存与逐音节覆盖，首选源缺失自动回退时如实标注实际播放源）；显示筛选（标记 / 年级 / 构型 / 来源 / 搜索）+ 分页。
    验收：`node scripts/debug-wordbank-filters.mjs` + `node scripts/debug-voice-admin.mjs`。
- **紧急载荷闭环**：注入后 iPad 刷新主页即亮橙色呼吸灯，点击（或综合巡航加权 ×5）优先抽到该题。
- 抽题模式：`all` / `three` / `confusion` / `emergency`。

## 课时奖励 progression = 星际目的地 / 火箭收藏 / 真实发射

> **Milestone 9：任务难度已取消。** 有了课文同步，出题范围只跟「学到哪一课」走；
> 原来的 Lv1–14 难度阶梯改造为**课时奖励系统**——完成课时发奖励，每一档奖励 = 一个星际目的地。
> 难度选择器从指挥官界面移除，奖励进度全部收进太空博物馆；机库右上角只保留「最新目的地」。

- **课时奖励（Lv1–14 = 14 个星际目的地）**：`public/js/rewards.js` 纯逻辑。
  - **完成一课时** = 该课全部可出题生字都至少练过一次（`progress.stats[missionId].attempts > 0`）；
    认读课（无可写生字）不计入课时总数；课时总数随教材同步词库增长，以 `/api/profile` 的 `lessonsTotal` 为准。
  - **每完成 2 课时升 1 档**：Lv1 低空轨道（0 课时起步）→ Lv2 高空轨道（2）→ … → Lv14 星际空间（26 课时）；
    门槛函数 `lessonsForRewardLevel` / `rewardLevelForLessons` / `nextRewardForLessons`。
  - **奖励在博物馆看**：「🛰️ 太空博物馆 → 星球图鉴 · 已解锁 × / 14」——课时奖励系统已并入星球图鉴：课时进度条
    （按**累计课时 0 → 26** 填充、带 14 档刻度，恰好跨过档位门槛时**不归零**）+
    「再完成 N 课时解锁 🌙 月球」，并说明课时判定规则；每张目的地卡片带档位徽章（Lv× · 当前目的地 / 下一站 / 已解锁 / 未解锁），
    未解锁卡片显示「完成 N 课时解锁」（下一站显示「再完成 N 课时解锁」）。
  - **最新目的地**：机库顶栏最右侧常驻徽标（🌍 低空轨道 … ✨ 星际空间），点开即进博物馆星球图鉴；
    tooltip 显示「下一份奖励：再完成 N 课时解锁 ××」。本局发射就飞这里。
  - **奖励与火箭都跟课时走**：目的地档位每 2 课时升 1 档；火箭收藏每完成 3 个单元解锁 1 枚（`unlockAt` = 完成单元数）。
    累计发射次数（`totalLaunches`）只作机库顶栏展示（「发射 N 次」），不再用于任何解锁，也不以「卫星数量」作为统计口径。
  - 结算页新增「📖 完成课时：一年级上册 · 识字2《金木水火土》」「🌍 新目的地解锁：🌙 月球（下一局飞这里）」
    与「课时 6 / 总课时 · 奖励 Lv4」（总课时以档案 `lessonsTotal` 为准）。
  - **注意**：旧档案的碎片化练习（东练一个字西练一个字）不算完成整课，所以升级后奖励档位会从 Lv1 重新爬；
    博物馆会显示「已完成 0 / 总课时」，跟着当前课文一课一课练即可回到更远的星球。
  - 旧接口 `POST /api/difficulty/select` 已下线（404），`GET /api/missions/next?difficulty=` 参数被忽略。

- **机库自选座驾**：机库「火箭选择」是一条**横向滑动条**（首屏可见 6–7 枚，右缘渐隐提示还有更多，

  「下一枚火箭」进度提示放在选择栏下方；点一枚即换它出战，选择存进 `data/progress.json` 的 `selectedRocketId`，刷新/重开都保留；
  太空博物馆的「火箭图鉴」里也每张卡片带「设为座驾」按钮。
  没自选时保持旧体验——自动用**最新获得**的一枚（解锁新火箭即自动换新），
  自选后固定用自选的这枚（不会被打出来的新火箭抢走）；右上角状态标签可点回「自动 · 最新火箭」。
- **真实发射**：发射场由 **Canvas 代码绘制**（`launch-fx.js drawLaunchScene`）——夜空星野、格构勤务塔架+摆臂+拉索、
  发射台+固定夹持器+导流槽、泛光灯，与火箭贴纸**同坐标系同画风**保证精确对齐；
  升空火箭使用当前拥有的火箭透明模型图，立于发射位，随高度视差下移场景并渐隐入太空。
  家长后台可选「每单元仅首次」：同单元首次发射后的后续发射跳过动画直接结算（`main.js enterLaunch` 按档案判定，`launch-fx.js` 本体不动）。

  入轨/抵达成功后动画多停留约 1 秒再进入结算。
- **真实卫星（Lv1–3 地球三层轨道）**：入轨释放生成的真实卫星透明模型（`public/images/sat/sat.png`），带光晕、轨道环、星芒粒子与发光汉字铭牌。
